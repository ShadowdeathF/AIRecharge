# 前后台连续动效实施计划

用户已确认沿第三套布局制作商城首页与后台仪表盘的可交互动效样板。本轮执行采用 superpowers:executing-plans，工作区复用 .worktrees/liquid-glass，基线 873a1db。

## 设计与技术决定

引入 Motion 14.9.0，使用共享布局、低回弹弹簧与退出动画。视觉依据为 docs/design/liquid-glass/selected-reference.png 和 Apple 官方 Liquid Glass 菜单过渡示例 5:10。桌面商品展示、手机紧凑行和真实业务流程为现有约束。

导航与控件采用玻璃材质，阅读面采用稳定表面。分类和日期的选中底板连续滑动。外观菜单的玻璃背景在触发按钮与面板之间变形，文字在面板展开后出现，关闭时收回。后台当天订单区域展开与收回时，图表宽度同步变化，小屏以原生对话框承载抽屉。主题使用短交叉过渡。

## 验收重点

- 操作状态即时提交，连续点击和反向操作衔接当前动画。
- 动画关闭期间菜单控件退出键盘访问，Escape、点外部、路由切换和焦点恢复合理。
- 当前页面只保留一个选中底板，各组共享动画标识独立。
- 减少动态效果可在初始与运行时生效，页面内容保持可读。
- 320、390、768、1024、1150、1440px 可用，暗色和品牌色覆盖全部新增控件。
- 使用真实 API 和临时浏览器分页夹具验证，交易数据由现有业务流程管理。
