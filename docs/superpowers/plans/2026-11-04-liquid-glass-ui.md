# Crystal Workspace 实施计划

> 执行采用 superpowers:executing-plans，在当前独立工作区依次完成任务。

## 目标与依据

完成用户选择的第 3 套前后台玻璃界面与动效。设计约束见 [设计规范](../specs/2026-11-04-liquid-glass-ui-design.md)。

## 架构和技术

复用 Next.js 16、React 19、现有 HSL 主题、Inter、Lucide 和商家图片。新增共用材质样式与页面动效，修改现有壳组件和商品布局。验证工作区为 .worktrees/liquid-glass，临时证据与进度存放 .local。

## 全局约束

- 商品右侧三行，每页三条，手机主推不超过 180px，普通行不超过 116px。
- 所有配色使用后台站点品牌色。明暗和语言选择均可操作。
- 动效覆盖正常页面与交互入口，减少动态效果时停止。
- 使用应用现有数据和接口进行验证，主控件在 320px 宽度可访问。

## 核查重点

- 分类、排序和分页时商品尺寸与结果次序符合预期。
- 后台侧栏折叠、手机抽屉和表格横向滚动保持可用。
- 弹层焦点、Escape、滚动锁定与主题透明层可读性。
- 减少动态效果下所有新增动画停止，离开页面取消未完成动画。
- 颜色切换覆盖商城、后台、对话框和财务工具条。
