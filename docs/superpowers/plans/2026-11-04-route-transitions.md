# 前后台全站页面过渡实施计划

本轮执行采用 superpowers:executing-plans。工作区复用 .worktrees/liquid-glass，分支 feat/route-transitions，基线 686c37d。

## 设计与实现

沿当前玻璃界面加入统一页面退场和入场。使用项目内 Next 16.1.6 已提供的 React ViewTransition 路由边界，保留原有 Link、router.push/replace/back 语义。前后台共用 PageTransition 承载主内容，导航与侧栏保持稳定。跨文档站内导航使用浏览器 View Transition，能力缺少时采用内容入场动画。

页面过渡采用轻微景深、位移和虚化，旧页退出约 220ms，新页稳定约 420ms。减少动态效果时停用位移和虚化。主题过渡与页面过渡分别定义样式。

## 验收约束

- 覆盖商品详情、购物车、结算、订单查询、登录注册、个人页及后台全部菜单。
- 覆盖 Link、程序跳转、重定向、浏览器前进后退、同页参数与站内表单跳转。
- 查询、选择、表单提交和付款等行为沿原入口执行，过渡围绕路由提交生效。
- 连续跳转、慢响应、错误页、滚动恢复和减少动态效果保持可用。
- 浏览器检查桌面与手机明暗模式、动效中间帧、旧页退出后内容与交互状态。

## 实施记录

44 项前端测试及独立 TypeScript 检查通过。生产构建通过。Next 缓存历史恢复采用 420ms 可取消入场，路径和参数由持续上下文标记。参数观察组件放在独立 Suspense 边界，主内容保留服务端输出。框架原生过渡使用当前 Next 的 viewTransition 实验开关，未升级依赖。
