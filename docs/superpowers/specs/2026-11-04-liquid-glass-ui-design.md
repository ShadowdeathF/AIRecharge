# Crystal Workspace 界面与动效设计

## 已选择的视觉方向

用户选择实际展示顺序中的第 3 套 Crystal Workspace。视觉依据见 [效果图](../../design/liquid-glass/selected-reference.png)。效果图包括桌面商城、桌面后台亮暗模式和手机商城。

## 目标

以清透玻璃导航、半透明工具条、清晰的数据表面和轻柔过渡形成统一的前后台界面。品牌色取自后台站点设置，主题和语言沿用应用现有入口。

## 页面和布局

- 桌面商城采用短横幅、分类与搜索工具条、左侧一个主推商品和右侧三行普通商品。普通商品每页三条，多余商品分页。主推与普通商品区底部对齐。
- 手机商城采用横向主推行和紧凑普通行，主推总高度不超过 180px，普通行不超过 116px。底部导航采用带安全间距的浮动玻璃样式。
- 后台覆盖仪表盘、订单、商品、库存、用户、采购、对账、分成、外观与设置等现有页面。导航采用分组浮动侧栏，顶栏与工具条具有轻微玻璃层次。
- 仪表盘具备紧凑日期筛选、四项指标、趋势图、交易明细和当天订单检查面板。小屏以抽屉展示当天订单。
- 表格、数字和正文采用高不透明度表面。导航、分段选择、弹层和工具条采用更清透的材质。

## 材质和字体

采用浅银灰与冷白基底、石墨暗色、细边缘高光和克制阴影。当前品牌色为站点配置的翡翠绿，各配色均从现有主题变量获取。字体复用 Inter、本机苹方和微软雅黑回退。图标复用与参考图一致的现有描边图标，商品与横幅复用商家图片和现有素材。

## 动效和无障碍

- 页面内容进入和分类结果变化采用小幅位移与淡入，时长约 240ms。
- 分段选择、按钮反馈和悬停采用 140–200ms 的颜色、阴影与轻微位移过渡。
- 下拉、筛选、模态框和侧栏采用 200–280ms 的淡入与缩放或滑入。
- 明暗切换采用短颜色过渡，焦点提示清晰可见。
- 减少动态效果设置启用时，位移、缩放和渐变动画即时停止。提高对比度或减少透明度设置启用时采用实色表面。
- 手机表单使用至少 16px 输入字体，主要触控目标至少 44px，320px 宽度下主控件可访问。

## 实施方式

在现有 Next.js 应用中增加共用材质与动效样式，调整商城与后台壳组件、共用弹层和商品布局。采用现有 React、CSS、Radix 和图标资源。组件状态、真实 API 和已有角色权限构成正常交互入口。

## 验收

前端现有行为测试通过，新增动效生命周期测试覆盖减少动态效果、取消和清理。构建和类型检查通过。浏览器验证商城分类、搜索、分页、外观菜单、后台导航、日期和当天订单检查、表单弹层、桌面与手机明暗模式。参考图和实际截图经过同状态的组合对照，根目录 design-qa.md 记录结果。
